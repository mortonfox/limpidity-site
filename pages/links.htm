Linking to Limpidity

It's easy. Just download the button to your web site and use the following HTML code:

<a href="http://www.limpidity.com"> <img src="lpdtnow.gif" width="88" height="31" border="0" alt="Limpidity Now!" /></a>

Feel free to customize the HTML code to suit your web page but please do not alter the button image itself. You may need to add a path or location before the button's file name.

The HTML code for that is as follows:

<a href="http://www.limpidity.com"> <img src="limpiditylogo.jpg" width="206" height="153" border="0" alt="Limpidity"></a>
